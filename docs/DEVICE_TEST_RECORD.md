## Android 广播与权限

- [ ] 首次授权蓝牙连接、蓝牙广播和通知后服务可以正常启动。
- [ ] 普通长度的手机名称会出现在 Windows 设备列表中。
- [ ] 名称过长或无名称时仍能广播应用服务 UUID，Windows 可以显示解锁服务设备占位名称。
- [ ] Windows 可以读取公钥；双方显示的指纹一致。
- [ ] 停止认证服务后，Windows 不会继续根据旧列表记录自动解锁。
- [ ] 蓝牙关闭和重新开启后，服务状态与实际广播情况一致。
- [ ] 收到连续请求、拒绝请求、GATT 中断和请求超时时，通知和内存中的请求状态正确清理。

## 用户确认与后台运行

- [ ] 自动模式能响应 Windows 发来的新随机挑战。
- [ ] 手动模式收到通知后，可通过系统身份验证批准认证。
- [ ] 拒绝、取消或超时后，Windows 保持锁定状态。
- [ ] 切换自动／手动模式后，新的请求采用当前模式。
- [ ] 应用退至后台、锁定手机、重启手机后，后台服务行为符合手机系统限制。
- [ ] 撤销权限或实施系统电池限制时，应用能显示合理的运行状态。
- [ ] 字体放大、浅色／深色主题及不同屏幕宽度下，Material 3 页面内容可阅读、按钮可操作。
